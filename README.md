## Movies API

Небольшой REST API для работы со списком фильмов. Проект сделан на FastAPI: данные хранятся в SQLite, а для работы с базой используются SQLAlchemy и асинхронные сессии.

## Основные возможности
В проекте моджно : добавлять фильмы, Получать список или отдельную запись, менять данные и удалять фильмы. Для списка есть фильтры по году и рейтингу, сортировка и постраничная выдача.

## Фильтры и сортировка
У списка фильмов есть параметры:
- year_min :   год выпуска от указанного значения
- year_max : год выпуска до указанного значения
- min_rating  : минимальный рейтинг
- order_by : сортировка
- limit :  количество фильмов которое будет в ответе
- offset : сколько записей надо пропустить

## Модель данных

Для хранения информации о фильмах используется таблица movies. У каждой записи есть ID, название, жанр, рейтинг и год выпуска.

## Ограничения
- Название фильма  от 2 до 200 символов.
- Жанр  от 2 до 100 символов.
- Рейтинг  от 0 до 10 
- Год выпуска  не раньше 1888 года и не позже нынешнего
- Все поля обязательны для заполненияя
